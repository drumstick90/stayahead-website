# StayAhead visualizations

These prototypes explore how papers can persist, return, and change position over time.

`stayahead-trend-atlas.fragment.html` is the editable visualization source. The public standalone build is generated at `public/visualizations/stayahead-trend-atlas.html`.

The committed demo uses synthetic paper identifiers, ranks, and scores. Real acquisition signals and licensed score data must remain private and must not be committed to this public website repository.
